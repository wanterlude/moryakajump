## Модули в `src/` (пилот)

Часть кода живёт в нормальном TypeScript и **вставляется** в `index.html` сборкой.
Бандл остаётся единственным артефактом: `exe`, варианты и инструменты про `src/`
ничего не знают.

```
node tools/build-src.js           # пересобрать вставку в index.html
node tools/build-src.js --check   # проверить, что вставка свежая
npm test                          # тесты модулей (node --test, без браузера)
npx tsc --noEmit                  # проверка типов
```

| Модуль | Что внутри |
|---|---|
| `src/game/field-layout.ts` | геометрия магнитного поля пружинных платформ |

Внутри `index.html` вставка обрамлена маркерами:

```
// <<< src: начало вставки — править в src/, не здесь >>>
// <<< src: конец вставки >>>
```

**Править код между маркерами нельзя** — перезапишется следующей сборкой.
`tools/check.js` сверяет вставку с `src/` при каждом прогоне.

### Как выносить следующий модуль

1. Написать модуль в `src/game/*.ts` с типами и тестами рядом (`*.test.ts`).
2. Добавить его в `MODULES` в `tools/build-src.js`.
3. Заменить старый код в `index.html` вызовом функций модуля.
4. `node tools/build-src.js && node tools/build-variants.js`.
5. `node tools/check.js` — версии и вставка; `node tools/golden.js` — отрисовка
   должна совпасть с эталонами. Если хеши не изменились, значит поведение
   сохранилось полностью; если изменились — разбираться, а не обновлять эталоны.
