# ❄️ Moryaka Jump

Зимний бесконечный платформер в **одном файле** — без сервера, сборки и интернета.

Главный герой — **Моряка**: прыгает по льдинам, ловит монеты, уворачивается от ветра и птиц, собирает усиления и дерётся с боссами Стужи.

## 🎮 Особенности

- 📦 **Один файл** — открыл `index.html` двойным кликом и играешь.
- 🖥️📱 **ПК и телефоны** — клавиатура, мышь, тач и наклон.
- 🌨️ **Светлый зимний интерфейс** — платформы, события и арены в одной палитре.
- 👾 **5 боссов × 3 фазы × 10 атак** — все атаки показывают телеграф заранее, у каждого босса своя арена.
- 🎁 **Награда за босса** — выбор одного из трёх редких усилений.
- 🥊 **Тренировка боссов** — любой босс из меню, без наград и записи в рекорд.
- 📅 **Ежедневные задания** — 6 типов: монеты, высота, босс, платформы, забеги и события; серия дней подряд.
- 🏆 **Глобальный рейтинг** — топ-10 сразу и прокрутка до 50 через Firebase Realtime Database, у каждого игрока показывается только лучший результат. Локальный топ — 5 лучших забегов.
- 🧭 **Боковые панели на ПК** — рейтинг слева и настройки справа на широком экране; сворачиваются, на телефоне скрыты.
- 👤 **Профиль и статистика** — лучший счёт, монеты, платформы, забеги, время, любимый персонаж и журнал боссов.
- 🏅 **15 достижений** — награды монетами за рекорды, коллекции и победы; выдаются один раз.
- 🌨️ **События** — метель и полыньи добавляют новые опасности к тёмноте, лавине, стенам и шипам.
- 🧍 **26 именованных персонажей**, рамки и **70 скинов платформ**.
- 💾 **Резервная копия** — экспорт и импорт прогресса кодом.

## 🕹️ Управление

| Действие | ПК | Телефон |
|---|---|---|
| Движение | `←` / `→` или `A` / `D` | тап слева / справа |
| Прыжок | `↑` / `W` / `Пробел` / клик | тап по центру |
| Пауза | `Esc` | кнопка в углу |
| Дуэль с боссом | `←` / `→` или мышь | тап по бокам |
| Стрельба в дуэли | автоматическая | автоматическая |

### 🖥️ Windows EXE

Готовая портативная сборка — в [GitHub Releases](https://github.com/wanterlude/moryakajump/releases/latest) (`Moryaka-Jump-<версия>.exe`). Установка не нужна: запустил файл — играешь.

Пересобрать и опубликовать: `cd desktop && npm install && npm run release` (для публикации нужен авторизованный `gh`).

## 📁 Структура

- `index.html` — вся игра: HTML, CSS и JavaScript в одном файле. **Единственный источник правды.**
- `test-boss.html` — тестовая сборка для проверки боссов (собирается из `index.html`).
- `test-frames.html` — галерея всех 211 рамок (собирается из `index.html`).
- `desktop/` — оболочка Electron и скрипты сборки Windows-exe.
- `tools/build-variants.js` — собирает тестовые сборки и `ui-preview.html`.
- `tools/sim/` — симулятор забегов с ботом: сборка `sim.html`, прогоны, замеры сложности.
- `AGENTS.md` — правила разработки: карта файла, релиз, проверки.
- `Changelog` — история изменений, новые версии сверху.
- `1.jpg`–`27.jpg`, `fon.jpg` — аватары и фон игры.

## 🛠️ Разработка

Все правки делаются в `index.html`; тестовые сборки и симулятор — производные от него.

```bash
node tools/check.js                   # сборки, синтаксис и версии — перед коммитом

node tools/build-variants.js          # пересобрать test-boss, test-frames, ui-preview
node tools/build-variants.js --check  # проверить, что варианты не разъехались

node tools/sim/make_sim.js            # собрать sim.html с хуками для бота
node tools/sim/run-node.js --runs=500 # прогон бота, сводка в tools/sim/last-run.md
```

Подробности, карта бандла и порядок релиза — в [AGENTS.md](AGENTS.md).


## 💾 Прогресс

Прогресс сохраняется в `localStorage` браузера. Чтобы не потерять накопленное, открой в меню кнопку **«БЭКАП»** и скопируй код — его можно вернуть в любой момент на этом или другом устройстве.
