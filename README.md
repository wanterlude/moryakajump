# Moryaka Jump

**Moryaka Jump** — зимний бесконечный платформер в одном HTML-файле. Главный герой — **Моряка**: он прыгает по льдинам, набирает высоту и монеты, открывает персонажей, рамки и скины платформ, собирает усиления и сражается с боссами.

## Особенности

- Один файл `index.html`: открывается двойным кликом, без сервера и сборки.
- ПК и телефоны: клавиатура, мышь, тач и наклон.
- Забеги: разные типы платформ, ветер, случайные события, квесты и перки.
- Прогресс: монеты, 26 именованных персонажей, рамки, 70 скинов платформ и рекорд.
- Боссы: 5 боссов, 3 фазы, 10 типов атак и отдельные зимние арены.
- Светлый зимний интерфейс, графика на canvas и локальные изображения.

## Запуск

Откройте `index.html` в браузере.

Тестовая сборка с панелью выбора босса и количества жизней — `test-boss.html`.

## Управление

- **ПК:** ←/→ или A/D — движение; ↑/W/Пробел/клик — прыжок; Esc — пауза.
- **Телефон:** тап слева/справа — движение; тап по центру — прыжок.
- **Дуэль с боссом:** движение мышью или ←/→ (на телефоне — тап слева/справа), стрельба автоматическая.

## Структура

- `index.html` — вся игра: HTML, CSS и JavaScript.
- `test-boss.html` — тестовая сборка для проверки боссов.
- `Changelog` — история изменений.
- `1.jpg`–`26.jpg`, `fon.jpg`, `character.png`, `babazaki.gif` — локальные материалы.

Прогресс сохраняется в `localStorage` браузера.
