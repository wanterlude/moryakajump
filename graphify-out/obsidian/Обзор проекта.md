# Обзор проекта Moryaka Jump

Обзорное хранилище: одна заметка на узел графа + карточка на сообщество,
сгенерированные [[graphify]] из `index.html` (снимок JS — `graphify-out/src/moryaka.js`).

## Ключевые подсистемы (сообщества графа)

- [[_COMMUNITY_Ядро и диалоги]] — корневой узел, диалоги и обвязка
- [[_COMMUNITY_Арена и тела боссов]] — отрисовка боссов и их арен
- [[_COMMUNITY_Дуэль атаки боссов]] — телеграфы, паттерны, сигнатурные атаки
- [[_COMMUNITY_Дуэль запуск и тренировка]] — запуск дуэли, тренировочный режим
- [[_COMMUNITY_Ветер]] — механика ветра
- [[_COMMUNITY_Ежедневные задания]] — дневной контент
- [[_COMMUNITY_HUD и индикаторы]] — интерфейс и статусы
- [[_COMMUNITY_Магазин платформ]] — магазины скинов

## Самые связанные узлы (god nodes)

- [[roundedRect()]], [[setFont()]], [[trackedText()]] — базовые помощники отрисовки
- [[update()]], [[draw()]] — главный цикл
- [[saveProgress()]] — сохранение

## Rebuild

После изменений в `index.html` пересобрать:

```bash
node -e "..." > graphify-out/src/moryaka.js   # извлечь inline JS
# затем pipeline graphify (detect → AST → build → export html/obsidian)
```
