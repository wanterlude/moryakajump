# ❄️ Moryaka Jump

Зимний бесконечный платформер в **одном файле** — без сервера, сборки и интернета.

Главный герой — **Моряка**: прыгает по льдинам, ловит монеты, уворачивается от ветра и птиц, собирает усиления и дерётся с боссами Стужи.

## 🎮 Особенности

- 📦 **Один файл** — открыл `index.html` двойным кликом и играешь.
- 🖥️📱 **ПК и телефоны** — клавиатура, мышь, тач и наклон.
- 🌨️ **Светлый зимний интерфейс** — платформы, события и арены в одной палитре.
- 👾 **5 боссов × 3 фазы × 10 атак** — все атаки показывают телеграф заранее, у каждого босса своя арена.
- 🎁 **Награда за босса** — выбор одного из трёх редких усилений.
- 🥊 **Тренировка боссов** — любой босс из меню, без наград и записи в рекорд.
- 📅 **Ежедневные задания** — 6 типов: монеты, высота, босс, платформы, забеги и события; серия дней подряд.
- 🏆 **Глобальный рейтинг** — топ-10 сразу и прокрутка до 50 через Firebase Realtime Database, отправка результата автоматическая.
- 🧭 **Боковые панели на ПК** — рейтинг слева и настройки справа на широком экране; сворачиваются, на телефоне скрыты.
- 👤 **Профиль и статистика** — лучший счёт, монеты, платформы, забеги, время, любимый персонаж и журнал боссов.
- 🏅 **15 достижений** — награды монетами за рекорды, коллекции и победы; выдаются один раз.
- 🌨️ **События** — метель и полыньи добавляют новые опасности к тёмноте, лавине, стенам и шипам.
- 🧍 **26 именованных персонажей**, рамки и **70 скинов платформ**.
- 💾 **Резервная копия** — экспорт и импорт прогресса кодом.

## 🕹️ Управление

| Действие | ПК | Телефон |
|---|---|---|
| Движение | `←` / `→` или `A` / `D` | тап слева / справа |
| Прыжок | `↑` / `W` / `Пробел` / клик | тап по центру |
| Пауза | `Esc` | кнопка в углу |
| Дуэль с боссом | `←` / `→` или мышь | тап по бокам |
| Стрельба в дуэли | автоматическая | автоматическая |

## 🚀 Запуск

| Файл | Назначение |
|---|---|
| `index.html` | основная игра — просто открой в браузере |
| `test-boss.html` | тестовая сборка: панель выбора босса и количества жизней |
| `test-frames.html` | тестовая галерея всех 211 рамок: анимация эффектов и номера по редкости |

## 📁 Структура

- `index.html` — вся игра: HTML, CSS и JavaScript в одном файле.
- `test-boss.html` — тестовая сборка для проверки боссов.
- `test-frames.html` — галерея всех рамок и их эффектов.
- `Changelog` — история изменений, новые версии сверху.
- `1.jpg`–`27.jpg`, `fon.jpg`, `character.png`, `babazaki.gif` — локальные материалы игры.

## 💾 Прогресс

Прогресс сохраняется в `localStorage` браузера. Чтобы не потерять накопленное, открой в меню кнопку **«БЭКАП»** и скопируй код — его можно вернуть в любой момент на этом или другом устройстве.
