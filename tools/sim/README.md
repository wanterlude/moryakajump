# Симулятор забегов Moryaka Jump

Собирает `sim.html` — копию игры с ботом и хуками для массовых прогонов.
В репозиторий и в exe не попадает, только для тестов.

## Запуск

```bash
node tools/sim/make_sim.js
python -m http.server 8765
# открой http://127.0.0.1:8765/sim.html
```

В консоли браузера:

```js
__simInit(200, 600000);   // сколько забегов и максимум шагов на забег
__simChunk(4000);         // считать ~4 секунды, вызывать повторно
__simMachine.runs         // результаты: score, cause, boss, duelStartLives, ...
__simMachine.done         // true, когда все забеги завершены
```

Отдельная проверка дуэли: `__simDuelTest(index, lives, maxSteps)` —
запускает бой с боссом и возвращает число попаданий, HP босса и победу.

## Что умеет бот

- Идёт по безопасным платформам, обходит шипы, полыньи и птиц.
- Собирает монеты и сердечки: монеты дают жизни (25 за жизнь, с перками — меньше),
  это критично, потому что босс с 0 жизней проигрывается мгновенно.
- Выбирает перки: жизни → множитель монет → монеты-за-жизнь → щиты → двойной прыжок.
- В дуэли использует MPC: откатывает состояние боя, перебирает точки перемещения
  на 40 кадров вперёд и выбирает вариант без попаданий. С 1 жизнью выигрывает
  большинство дуэлей без единого попадания.

## Результаты (2026-10-26, 800 забегов)

| Метрика | Значение |
|---|---|
| Максимум | **103 516** (босс 3 пройден, 3-я арена) |
| ≥ 90 000 | 3 забега |
| ≥ 60 000 | 4 забега |
| Медиана | ~14 300 |
| 90-й перцентиль | ~27 300 |

Без MPC-уклонения бот не проходил первого босса: с 0 жизнями дуэль
завершалась мгновенно. После обучения дуэль выигрывается с 1 жизнью,
а монеты и перки дают запас жизней на следующие арены.
